# Patient Management System

A full-stack patient record management application built with a FastAPI backend and a Streamlit frontend featuring a modern Neumorphic UI design.

---

## Features

* Patient Dashboard: View all registered patients with auto-calculated BMI and health verdicts (Under Weight, Normal, Observation required..).
* Add Patient: Easily register new patients with input validation.
* Update Patient: Modify existing patient records dynamically.
* Delete Patient: Remove records seamlessly with instant UI confirmation.
* System Health Diagnostics: Live monitoring of backend health endpoints.
* Neumorphic Interface: Soft shadows, inset cards, and modern styling built directly into Streamlit.
